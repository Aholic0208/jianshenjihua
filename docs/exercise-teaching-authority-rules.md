# 动作教学权威规则摘要

这份摘要用于约束站内动作图片与视频的“正确示范 / 常见错误”生成逻辑，避免只按主观感觉摆姿势。每个动作至少要在画面里拉开一个最明显的视觉差异点，再去配文案和高亮。

## 热身、有氧、核心、拉伸

- `warmup-march`
  - 正确：躯干直立，提膝来自髋，摆臂自然，落地轻。
  - 错误：后仰甩腿、耸肩、跺地。
  - 关键视觉点：正确版“躯干稳定”，错误版“靠后仰把腿甩上来”。
  - 来源：
    - https://www.nhs.uk/live-well/exercise/how-to-warm-up-before-exercising/
    - https://www.uhsussex.nhs.uk/resources/standing-exercises/

- `plank`
  - 正确：耳-肩-髋-踝接近一直线，肘在肩下，核心收紧。
  - 错误：塌腰、撅臀、耸肩、憋气。
  - 关键视觉点：侧面直线一断就判错。
  - 来源：
    - https://www.nasm.org/resource-center/exercise-library/plank
    - https://blog.nasm.org/standard-plank-with-variations

- `treadmill-walk`
  - 正确：头看前方，手臂自然摆动，不长期抓扶手。
  - 错误：死抓扶手、低头、步幅过大、肩颈僵硬。
  - 关键视觉点：正确版像地面快走，错误版像被扶手“吊住”。
  - 来源：
    - https://www.mayoclinic.org/healthy-lifestyle/fitness/in-depth/walking/art-20046261?p=1
    - https://www.acefitness.org/resources/pros/expert-articles/8855/walking-pads-health-benefits-and-usage-guidelines/

- `step-cardio`
  - 正确：领先脚整脚踩稳台面，膝盖跟脚尖同向，发力来自踩台腿。
  - 错误：半脚踩台、膝内扣、前扑、台阶过高。
  - 关键视觉点：先看脚是否踩满台面，再看膝盖轨迹。
  - 来源：
    - https://www.acefitness.org/resources/everyone/exercise-library/28/step-up/

- `stretch-full-body`
  - 正确：先拉长身体，再侧屈或前屈；动作慢、呼吸稳、只到轻微牵拉感。
  - 错误：弹震式拉伸、塌腰耸肩、前塌扭转、追求疼痛。
  - 关键视觉点：正确版先有“延展感”，错误版一上来就塌缩扭。
  - 来源：
    - https://www.nhs.uk/live-well/exercise/how-to-stretch-after-exercising/
    - https://insideguide.nhs.uk/hospitals/helping-yourself/healthy-body/exercise/cool-down-and-stretching/

## 下肢力量

- `bodyweight-squat`
  - 正确：髋先向后，胸口打开，膝盖对准第 2-3 脚趾，脚跟压地。
  - 错误：膝内扣、胸掉下去、脚跟抬起、腰椎明显圆背或反弓。
  - 关键视觉点：正面看膝轨迹，侧面看躯干与胫骨关系和脚跟。
  - 来源：
    - https://www.acefitness.org/resources/everyone/exercise-library/135/bodyweight-squat/
    - https://blog.nasm.org/biomechanics-of-the-squat

- `goblet-squat`
  - 正确：负重贴胸，躯干更直立，肘靠近身体，膝跟脚尖同向。
  - 错误：负重离胸、膝内扣、上身前扑、肘外飞。
  - 关键视觉点：先看重量是否贴胸，再看躯干是否直立。
  - 来源：
    - https://www.nasm.org/resource-center/exercise-library/goblet-squat
    - https://www.acefitness.org/resources/everyone/exercise-library/362/goblet-squat/

- `glute-bridge`
  - 正确：脚跟压地，臀主动夹紧，肩-髋-膝接近一线，骨盆水平。
  - 错误：腰椎过伸、骨盆歪斜、脚跟发飘、上下过快。
  - 关键视觉点：顶端看的是“成线”而不是“抬越高越好”。
  - 来源：
    - https://www.acefitness.org/resources/everyone/exercise-library/49/glute-bridge/

- `leg-press`
  - 正确：背和尾骨贴靠垫，脚跟不离板，膝跟脚尖同向，顶端不锁死。
  - 错误：臀离座、膝锁死、脚跟离板、膝内扣。
  - 关键视觉点：斜侧面最先看臀是否离座和膝是否锁死。
  - 来源：
    - https://www.acefitness.org/resources/everyone/exercise-library/154/seated-leg-press/
    - https://exrx.net/WeightExercises/Quadriceps/SLSeatedLegPress

## 上肢力量

- `incline-push-up`
  - 正确：耳-肩-髋-踝成线，肘约 45 度，下放胸靠近支撑面。
  - 错误：塌腰、撅臀、肘外飞、借惯性弹起。
  - 关键视觉点：侧面看身体直线，正面看肘轨迹。
  - 来源：
    - https://www.nasm.org/resource-center/exercise-library/incline-push-up

- `dumbbell-row`
  - 正确：背平，肩稳，肘沿肋侧向后走，躯干不跟着扭。
  - 错误：扭转躯干、耸肩、甩铃、塌腰抬头。
  - 关键视觉点：看“哑铃上来，躯干不打开”；肘贴肋后拉。
  - 来源：
    - https://www.acefitness.org/resources/everyone/exercise-library/126/single-arm-row/

- `band-row`
  - 正确：胸口打开，肘沿身体两侧后拉，回程受控。
  - 错误：含胸圆肩、肘外飞、回放太快、后仰借力。
  - 关键视觉点：终点手回到下肋附近，不是耸肩拉很高。
  - 来源：
    - https://www.massgeneral.org/assets/mgh/pdf/orthopaedics/sports-medicine/physical-therapy/mass-general-theraband-strengthening-for-the-shoulder.pdf
    - https://www.hss.edu/article_resistance-band-workout.asp

- `lat-pulldown`
  - 正确：轻微后倾，肩胛先下沉后收，杆到上胸前。
  - 错误：大幅后仰、耸肩探头、拉到颈后、顶部失控。
  - 关键视觉点：正确版“杆到上胸前”，错误版“上身后仰过大且杆线乱跑”。
  - 来源：
    - https://blog.nasm.org/biomechanics-of-the-lat-pulldown

- `machine-chest-press`
  - 正确：把手高度与中胸平齐，肩胛稳定贴靠靠垫，手腕中立。
  - 错误：座椅高度错、肩前冲离垫、肘过度外张、回放失控。
  - 关键视觉点：先看把手高度，再看肩胛是否前冲。
  - 来源：
    - https://www.acefitness.org/resources/everyone/exercise-library/188/seated-chest-press/
    - https://www.nasm.org/resource-center/exercise-library/chest-press-machine

- `seated-cable-row`
  - 正确：胸口立住，肘贴身后拉，把手进腹，回程仍直立。
  - 错误：身体大幅前后晃、圆肩含胸、肘外飞。
  - 关键视觉点：好动作“把手进腹且胸口始终立着”，坏动作“肩往前塌、身体来回摆”。
  - 来源：
    - https://www.acefitness.org/resources/everyone/exercise-library/48/seated-row/
    - https://www.acefitness.org/resources/everyone/exercise-library/168/seated-row/
