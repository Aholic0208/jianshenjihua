# 健身项目

这是一个用于健身相关产品或应用开发的项目工作区。当前仓库已按文档、素材、笔记和代码进行基础分区，方便后续需求沉淀、设计协作、问题记录和代码开发。

## 目录结构

```text
docs/              产品文档、PRD、需求迭代记录、关键决策
assets/design/     设计效果图、UI 参考和设计素材
assets/bug/        测试报错截图和问题复现素材
assets/reference/  参考图、灵感和竞品资料
notes/             学习笔记、踩坑记录和技术方案
src/               项目代码
```

## 开发约定

- 代码统一放入 `src/`。
- 文档统一放入 `docs/`。
- 技术学习和开发经验记录统一放入 `notes/`。
- 素材按用途放入 `assets/` 下对应子目录。
- 后续开发 AI 请先阅读 `AGENTS.md`。
- 阶段性开发完成后，将代码提交并推送到项目对应的 GitHub 仓库。
